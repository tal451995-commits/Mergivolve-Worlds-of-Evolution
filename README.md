# Mergivolve — Worlds of Evolution

An original, polished mobile-first merge and evolution game featuring a living illustrated world, 5-tier upgradeable generators, monster sanctuary, minigames, and bilingual support (Hebrew RTL & English LTR).

## Local Running Instructions

1. Ensure you have [Node.js](https://nodejs.org/) installed, or any local static web server (such as Python's `http.server`).
2. Run the development preview server:
   ```bash
   npm install
   npm start
